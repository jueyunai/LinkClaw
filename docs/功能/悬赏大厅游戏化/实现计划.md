# 悬赏大厅游戏化改造 - 实现计划

## Context

LinkClaw 当前是一个"平庸的活动匹配平台"。本次改造将其包装为**悬赏榜**风格的游戏化平台：活动→悬赏任务，嘉宾→赏金猎人，AI 分身→小精灵。核心是在现有架构上做增量修改，不重建底层。

设计文档：`docs/features/design/2026-03-18-bounty-hall-gamification-design.md`

---

## 执行计划（10 个 Commit，按顺序执行）

### Commit 1: 数据基础层

**A1** 新建 `supabase/migrations/008_bounty_gamification.sql`
- `profiles` 新增 `hunter_level integer NOT NULL DEFAULT 1` + CHECK 1-6
- `events` 新增 `bounty_rank integer NOT NULL DEFAULT 1` + CHECK 1-5
- 通过 `mcp__supabase__apply_migration` 执行

**A2** 修改 `src/types/database.ts`
- 新增 `HunterLevel`(1-6)、`BountyRank`(1-5) 类型
- 新增 `HUNTER_LEVEL_META` 常量（key + color，不含文案）
- `Profile` 接口新增 `hunter_level: HunterLevel`
- `Event` 接口新增 `bounty_rank: BountyRank`
- `profiles.Insert` 中 `hunter_level` 标记可选（DB DEFAULT）
- `events.Insert` 中 `bounty_rank` 标记可选（DB DEFAULT）

**A3** 新建 `src/lib/admin.ts`
- `isAdmin(email: string | undefined): boolean` — 从 `process.env.ADMIN_EMAILS` 读取白名单
- 更新 `.env.local.example` 新增 `ADMIN_EMAILS`

### Commit 2: 核心业务逻辑

**B1** 修改 `src/app/[locale]/registrations/actions.ts`
- `applyToEvent()`: profile select 加 `hunter_level`，event select 加 `bounty_rank`
- 新增校验：`hunter_level < bounty_rank` → 拒绝接单
- `respondToInvitation()` 不改（指名委托不校验段位）

**B2** 修改 `src/app/[locale]/events/actions.ts`
- `parseEventFormData()` 新增读取 `bountyRank`
- `validateEventFormValues()` 新增 1-5 范围校验
- `createEvent()` 和 `updateEvent()` 的 insert/update 对象包含 `bounty_rank`

**B3** 修改 `src/lib/ai/recommendation.ts` + `src/lib/ai/pipeline/types.ts`
- `EventDetailInput` 扩展 `bounty_rank` 字段
- `getEventRecommendations()` 新增可选参数 `hunterLevel?`，有值时过滤 `bounty_rank <= hunterLevel`

### Commit 3: UI 基础组件

**C1** 新建 `src/components/features/rank-badge.tsx`
- Props: `level: HunterLevel | BountyRank`, `size: 'sm' | 'lg'`
- 使用 `HUNTER_LEVEL_META` 颜色，`useTranslations('hunter')` 获取段位名
- 传说段位加 `animate-pulse`

**C2** 新建 `src/components/features/sprite-bubble.tsx`
- Props: `message: string`, `variant: 'info' | 'success' | 'warning'`
- 左侧精灵图标 + 右侧气泡框
- variant 控制气泡背景：amber-50 / emerald-50 / rose-50

**C3** 修改 `src/app/globals.css`
- `:root` 配色从冷灰切换到暖色公会风格（oklch 格式）
  - background → 暖米色 stone-50
  - primary → 琥珀金 amber-700
  - card → 淡暖色 stone-50
  - border → 暖灰 stone-300
- 只改亮色模式，`.dark` 不动

### Commit 4: 新增翻译 key
