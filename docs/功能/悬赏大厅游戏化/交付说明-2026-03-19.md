- **日期**：2026-03-19
- **范围**：悬赏大厅世界观换皮 + 猎人段位体系 + 悬赏门槛 + 小精灵交互 + 管理后台 + 测试与验收
- **状态**：已交付，可进入验收/提测/提交阶段

---

## 1. 本次交付概览

本次改造将 LinkClaw 从原本的“活动匹配平台”包装为**悬赏大厅**风格的游戏化平台，核心完成了以下几类能力：

1. **数据层扩展**
   - `profiles.hunter_level`：猎人段位（1-6）
   - `events.bounty_rank`：悬赏最低接单段位（1-5）

2. **服务端业务规则落地**
   - 猎人接单时，服务端会校验 `hunter_level >= bounty_rank`
   - 指名委托（`respondToInvitation()`）保持不受段位限制
   - 推荐入口统一按段位过滤推荐候选

3. **前端沉浸式换皮**
   - 首页升级为“悬赏大厅”
   - 活动卡片升级为“悬赏任务卡”，支持段位徽章、左侧段位色条、锁定态
   - 详情页新增小精灵评估与段位禁用提示
   - 档案页新增猎人段位展示
   - 导航、我的活动、发布页、管理页同步切换到悬赏世界观

4. **后台管理能力**
   - 新增 `/[locale]/admin/hunters`
   - 支持管理员手动调整猎人段位
   - `/admin` 路径已在 middleware 与页面/action 双层保护

5. **彩蛋功能**
   - 首页新增“小精灵巡逻报时”
   - 会根据时间段切换不同侦察问候
   - 当存在下一段位可解锁任务时，会额外提示“再升 1 级可解锁 N 份悬赏”

## 5. 建议人工验收路径

建议按下面 4 条主线验收：

### 5.1 猎人视角
1. 登录 guest 账号进入首页
2. 确认顶部为“悬赏大厅”
3. 确认存在小精灵侦察气泡
4. 确认高段位任务在首页呈现锁定态
5. 打开高段位任务详情页，确认：
   - 有段位徽章
   - 有小精灵评估文案
   - 接单按钮禁用
6. 打开同段位/低段位任务，确认可正常接单

### 5.2 悬赏人视角
1. 登录 organizer 账号
2. 打开发布页，确认存在“最低接单段位”选择器
3. 选择不同段位发布悬赏
4. 打开管理页，确认 `bountyRank` 可回显并修改
5. 进入“我的悬赏”，确认文案已换皮

### 5.3 管理员视角
1. 配置 `ADMIN_EMAILS`
2. 用白名单账号访问 `/[locale]/admin/hunters`
3. 修改某个猎人的段位
4. 返回档案页或大厅验证该段位已生效

### 5.4 国际化视角
1. 在 `zh` 与 `en` 间切换
2. 抽检：首页、详情页、导航、我的页面、admin 页面
3. 确认世界观术语一致，没有出现旧“活动 / 嘉宾 / 主办方”残留关键路径
